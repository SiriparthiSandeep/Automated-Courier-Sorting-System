# Automated Courier Sorting System

## Project Overview
This project features an automated Courier Sorting System built using **OpenPLC Editor**. The control logic optimizes conveyor operations to seamlessly route packages to their designated destinations based on specific sorting criteria (barcode scanning and material recording) using pneumatic pushers.

## Core Files
- `project.json`: Contains the complete IEC 61131-3 logic programs, data types, and configuration blocks managed by OpenPLC.

## How to View and Run
1. Download and open the [OpenPLC Editor](https://autonomylogic.com/).
2. Clone or download this repository to your computer.
3. In OpenPLC Editor, select **Open Project** and open the folder containing the `project.json` file.
